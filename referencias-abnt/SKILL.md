# Referências ABNT

Extraia somente dados fornecidos ou verificáveis: autoria, título, edição, local, editora, data, periódico, volume, número, páginas, DOI ou URL e data de acesso quando pertinente. Marque campos ausentes em vez de completá-los por inferência.

Produza a referência padronizada e uma ficha dos dados usados. Ordene e uniformize toda a lista apenas após confirmar o critério do manual institucional. Para DOI e URL, preserve o identificador canônico. Não fabrique edição, paginação, DOI ou data.
