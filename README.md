# Skills para Mestrado no Brasil

Catálogo de skills para apoiar uma pesquisadora de mestrado no Brasil. Todas privilegiam português brasileiro acadêmico, autoria da pesquisadora, fontes verificáveis e respeito ao manual do PPG.

## Instalação

Clone este repositório e copie as pastas das skills desejadas para `~/.codex/skills/`. Reinicie o Codex após a cópia.

```bash
git clone <URL-DO-REPOSITORIO>
cp -R skills-mestrado-br/* ~/.codex/skills/
```

## Catálogo

| Skill | Uso |
| --- | --- |
| `mestrado-br` | Triagem e encaminhamento de demandas amplas. |
| `projeto-pesquisa` | Projeto, problema, objetivos, método e cronograma. |
| `busca-fontes-academicas` | Busca reprodutível e validação de fontes. |
| `revisao-literatura` | Revisão narrativa, integrativa ou de escopo. |
| `revisao-sistematica` | Protocolo, seleção e síntese rastreável. |
| `referencial-teorico` | Conceitos, autores e lente analítica. |
| `artigo-cientifico` | Planejamento e redação de manuscrito. |
| `secoes-academicas` | Introdução, método, resultados, discussão e conclusão. |
| `revisor-abnt` | Conformidade ABNT e manual institucional. |
| `referencias-abnt` | Construção e padronização de referências. |
| `auditoria-citacoes` | Conciliação entre texto e bibliografia. |
| `revisao-texto-academico` | Clareza, coesão e precisão da redação. |
| `parecer-artigo` | Parecer construtivo de pré-submissão. |
| `integridade-academica` | Riscos de autoria, fontes, dados e ética. |
| `qualificacao-defesa` | Apresentação, arguição e respostas à banca. |

Não use travessões no texto acadêmico produzido. Nenhuma skill deve inventar fontes, dados, resultados ou referências.
