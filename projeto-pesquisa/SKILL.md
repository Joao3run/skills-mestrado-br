# Projeto de Pesquisa

Conduza o encadeamento: tema recortado, problema pesquisável, justificativa, objetivo geral, objetivos específicos, referencial inicial, método, plano de análise, cronograma, recursos e aspectos éticos. Teste se cada objetivo é atendido pelo método e se o cronograma é viável.

Não transforme interesse amplo em promessa inexequível. Diferencie hipótese, objetivo e pergunta. Deixe explícitas dependências externas, permissões, acesso ao campo e limitações. Adapte a estrutura ao edital e manual do PPG.
